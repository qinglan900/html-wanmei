业务规则
  • PV（页面浏览量）：同一用户同一页面多次浏览会重复计数，反映页面被访问的总次数
  • UV（独立访客数）：按设备唯一标识去重，同一用户多次访问只计1次，反映实际触达的用户规模
  • 开屏+弹窗+顶部Banner+腰部Banner去重曝光UV：开屏、首页弹窗、首页顶部Banner、首页腰部Banner四个入口位置去重后的独立访客数，用户通过任一入口进入均只计1次
  • 开屏+弹窗+顶部Banner+腰部Banner去重点击UV：上述四个入口位置去重后的独立点击访客数，用户点击任一入口均只计1次
  • 累计计算方式：全部车型时对设备号去重统计，货六车型时对车牌号进行去重统计（限制货六）
  • 数据范围：活动上线日期（2026-05-15）至昨日（2026-06-09），每日凌晨更新前一日数据

业务规则
  • 可用积分计算：收入积分 + 补发积分 - 已兑换积分 - 过期积分 = 当前可用积分
  • 累计发放积分：截至T-1日，系统累计向货六用户发放的积分总量
  • 累计领取积分：截至T-1日，累计报名达标车辆发放积分数量
  • 累计兑换次数：截至T-1日，用户用积分兑换优惠券的订单数量
  • 累计兑换积分：截至T-1日，用户用积分兑换优惠券的积分总量
  • 累计核销积分：截至T-1日，商户实际核销的优惠券对应的积分总量
  • 累计通行车辆数：截至T-1日，货六ETC车辆在活动路段的总通行次数（去重按车牌号）
  • 累计有效报名车辆数：截至T-1日，完成活动有效报名的货六车辆总数
  • 领取率 = 累计领取积分数 / 累计发放积分数
  • 有效报名率 = 累计有效报名车辆数 / 累计通行车辆数（货六ETC）
  • 活动达标率 = 累计报名达标车辆数 / 累计有效报名车辆数
  • 车辆兑换率 = 累计兑换车辆数 / 累计报名达标车辆数
  • 人数兑换率 = 累计兑换人数 / 累计有效报名人数
  • 核销率 = 累计核销车辆数 / 累计兑换车辆数
  • 数据范围：活动上线日期至T-1日，每日凌晨更新前一日累计数据，每日更新到最新状态
